# Greeting fixture

## Instructions

1. Ask for the preferred name if no name was provided.
2. Respond with one friendly greeting sentence using that name.
3. Return plain text only. No tools, files, network access, or credentials are needed.

## Example

Input: Greet Taylor.
Output: Hello, Taylor! Have a lovely day.
